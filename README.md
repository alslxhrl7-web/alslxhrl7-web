## 🧭 How I Work

```text
1. 구조로 나누기   — 재미의 핵심 루프를 먼저 정하고, 시스템을 쪼개 기획서로 만든다
2. 직접 만들기     — AI 코딩 도구와 생성형 AI로 플레이 가능한 프로토타입을 빠르게 만든다
3. 숫자로 확인하기 — 승률·밸런스·폴리곤 수처럼 확인할 수 있는 값으로 결과를 검증한다
4. 기록하기       — 결정한 이유와 실패한 시도를 GitHub와 문서에 남긴다
```
